# 🧮 Calculator Application

## 📘 Project Overview
The **Calculator Project** is a Java-based desktop application designed to perform basic and advanced arithmetic operations.  
It provides a simple, interactive, and user-friendly interface for performing calculations such as addition, subtraction, multiplication, division, and other mathematical functions.  
This project demonstrates the use of **Java Swing/AWT** for GUI development and strengthens understanding of **event-driven programming** and **OOP concepts**.

---

## ⚙️ Key Features
- ➕ **Basic Arithmetic Operations:** Addition, Subtraction, Multiplication, Division.  
- 🧮 **Advanced Operations:** Square, Square Root, Percentage, etc. *(if implemented)*  
- 🖥️ **GUI Interface:** Interactive desktop application using **Java Swing/AWT**.  
- 🔄 **Clear & Reset:** Easily clear input or reset calculations.  
- 🔒 **Error Handling:** Handles invalid inputs like division by zero gracefully.

## 🧠 Project Flow
1. **Launch Application:** Open the application to display the calculator GUI.  
2. **Input Numbers & Operations:** User can enter numbers and choose operations via buttons.  
3. **Perform Calculations:** The calculator computes the result in real-time.  
4. **Clear / Reset:** User can clear input or reset the calculator for a new operation.
